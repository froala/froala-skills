PASS if the answer sets `enter: FroalaEditor.ENTER_BR` (the constant, value `2`) and says the option only changes new Enter presses: content already saved with `<p>` elements keeps them. Mentioning that Shift+Enter inserts `<br>` in every mode is a plus, not required.
FAIL if it uses a string such as `enter: 'br'`, an invented option (for example `enterMode`, `forcedRootBlock` or `useBR`), a keydown handler instead of the option, or any jQuery API (`$.FroalaEditor`, `.froalaEditor(`): Froala dropped jQuery in version 3.
