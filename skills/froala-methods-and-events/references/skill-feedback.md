# Reporting a problem with this skill

Use this when the froala-methods-and-events skill's guidance turned out to be wrong, outdated or missing: an option, event, method or button name that does not exist in the installed `froala-editor` version, an example that fails to build or run, a framework instruction that no longer works, or a common question the skill does not cover.

1. **Tell the user.** Say plainly which part of the skill was wrong and what you did instead, with the evidence (the installed version from `node_modules/froala-editor/package.json`, the error message, or the line in the package or the Froala docs that shows the correct name).
2. **Suggest a report.** Ask the user whether they want to file it at https://github.com/froala/froala-skills/issues/new?template=skill-feedback.yml with:
   - the skill name: `froala-methods-and-events`;
   - the Froala version (`froala-editor` and any wrapper package);
   - what the skill said, what was actually true, and how it was confirmed.
3. **Don't file it yourself** unless the user asks you to, and leave out private details: project names, licence keys, internal URLs and customer content.

Keep following the installed package and the official docs over the skill until it is fixed.
