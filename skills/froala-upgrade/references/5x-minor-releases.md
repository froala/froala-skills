# Froala 5.x minor releases (5.0.0 → 5.6.0)

Sources: the [changelog](https://froala.com/wysiwyg-editor/changelog/), [Migrating from Froala V4 to Froala V5](https://froala.com/wysiwyg-editor/docs/migrating-from-froala-4-to-froala-5/?utm_source=froala-skills&utm_medium=agent-skill&utm_content=froala-upgrade) (options, methods and events per version) and the npm packages `froala-editor` 5.0.0 – 5.6.0 (each feature below was checked in the package of the version named).

Minor releases inside 5.x keep the same licence key and add features; none removed an option or a toolbar command (package diff 5.0.0 → 5.6.0). Still read the rows between the installed and the target version: some change default output or wrapper behaviour.

## Which version a feature needs

| Feature | Needs | Plugin / API |
|---|---|---|
| Export to Word | 4.7.0+ | `exportToWord`, button `export_to_word` |
| Import from Word | 5.0.0+ | `importFromWord`, button `import_from_word`; `importFromWordMammoth` for bundlers 5.3.0+ |
| Code Snippet | 5.0.0+ | `codeSnippet` |
| AI Assist | 5.1.0+ | `aiAssist`; needs `aiSupplementalTermsAccepted: true` or the buttons only show a terms popup |
| Image Filerobot | 5.2.0+ | `imageFilerobot` (load `js/third_party/imageFileRobot.min.js` yourself) |
| Real-time collaboration, comments, version history | 5.3.0+ (sync improved in 5.3.1) | `collaborative` |
| Svelte wrapper | 5.3.0+ | `svelte-froala-wysiwyg` |
| Custom font size input | 5.3.0+ | `fontSize` default list ends with `'custom'`; `fontSizeCustomMin`, `fontSizeCustomMax` |
| AI Chat, Improve Writing, speech-to-text, inline suggestions | 5.4.0+ | `aiChatAssistant` button, `aiChat*` options, `inlineSuggestions` |
| Markdown API | 5.4.0+ | `markdown.getMarkdown()`, `markdown.setMarkdown()`, `markdown.beforeGet` / `markdown.set` events (Markdown mode itself: 4.0.0+) |
| Headless mode | 5.5.0+ | `headless: true` (initial, limited feature support) |
| Accessibility Checker, Paint Format | 5.6.0+ | `accessibilityChecker`, `paintFormat` |
| Email and phone links, draggable popups | 5.6.0+ | `linkEmailDomains`, `linkPhonePattern`, `popupDraggable` |

If the user wants a feature, the target version must be at least the one in this table.

## Behaviour changes to check when crossing a release

### 5.0.0 / 5.0.1
- New tables: `tableDefaultBorderWidth` and `tableDefaultBorderStyle` default to `''` (4.6.0 – 4.7.1: `'1px'`, `'solid'`).
- `tableCellBackground` toolbar command is back.
- 5.0.1: `toolbarButtonsEnabledOnEditorOff` keeps chosen buttons active after `editor.edit.off()` (default list in 5.6.0: `print`, `fullscreen`, `export_to_word`, `getPDF`, `html`). 5.0.1 also added `tableHorizontalResizer` and `tableVerticalResizer`.

### 5.1.0
- New events `drop.beforeCleanup`, `drop.afterCleanup`. The changelog notes `paste.afterCleanup` no longer fires when a table is dragged inside the editor: re-test code that relies on it.

### 5.2.0
- Inline styles generated by Froala partly fixed for strict CSP (no `unsafe-inline`) — "Fixed (partially)" in the changelog.
- `serialize-javascript` raised to 7.0.3 (security fix; the React wrapper 5.6.0 depends on `^7.0.3`).

### 5.3.0
- Import from Word accepts a Mammoth instance through `importFromWordMammoth` (needed with Vite and other module bundlers).
- Clipboard content is no longer persisted in `localStorage` (changelog).
- The font size dropdown gains a custom size entry (`'custom'` in the default `fontSize`). Projects that set `fontSize` themselves keep their list.

### 5.4.0
- `aiAssistRequest` can stream through a third `onChunk` argument and report `webSearchUsed`.
- `inlineSuggestions` defaults to `true`: once AI Assist is configured, the editor requests ghost-text suggestions while the user types. Set `inlineSuggestions: false` if that traffic isn't wanted.

### 5.5.0
- `preserveListMarkerStyle` (default `true`) controls whether bold or italic on a whole list item is stored on the `<li>` or as `<strong>` / `<em>` inside it. Compare list markup in the round-trip diff.
- `image.replaced` now also passes the previous `src` as a third argument; `video.replaced` passes the upload response and the previous `src`.
- AI Chat: `aiChatWebSearchEnabled` and `aiChatReasoningEnabled` are now requests that a model's `webSearch: false` / `reasoning: false` overrides; `aiAssistRequest` receives `regenerate: true` on "Try again".

### 5.6.0
- **Licence behaviour.** The red "unlicensed" banner is replaced by a short notice next to "Powered by Froala" (missing / trial / invalid / expired). With no key or the trial key, `localhost` now shows the same notice as a live site, and `html.get()` appends `<p data-f-id="pbf">Powered by Froala Editor</p>` — so the paragraph ends up in saved content and, in React, in the `model`. **Set a real key before saving content.** Loading a document back with `html.set()` removes the paragraph, so re-saving affected documents with a licensed editor cleans them.
- **Security:** XSS fixes in the Word Export plugin. A reason to upgrade any project that uses `exportToWord`.
- React wrapper: under StrictMode `initialized` no longer runs three times; `onModelChange` no longer fires when the editor loads (only on real changes); passing the editor's own value back into `model` no longer clears undo history; props and editor options are type-checked (new TypeScript errors can surface); `initialize()` / `destroy()` work on a ref; a Vite 8 app no longer gets a blank page with the default import. Code that relied on the load-time `onModelChange` must change.
- Angular wrapper: after a Reactive Forms reset the first edit updates the form value; popups show above Angular Material v21 dialogs.
- New default toolbar buttons `paintFormat` and `accessibilityChecker` (see SKILL.md step 5).

## Patch releases

Patch releases can also add options (5.0.1 did). Read their changelog entries too, and upgrade the wrapper to the same patch version.
