# Reporting a problem with this skill

Use this when the guidance in the `froala-ai-assist` skill proved **wrong** (an option, event, method, button or file name that doesn't exist, or code that fails), **outdated** (it no longer matches the installed `froala-editor` version), or **missing** something the task needed.

1. **Tell the user** what the skill said, what actually happened, and what worked instead. Base the fix on the installed package and the Froala docs, not on the skill.
2. **Suggest filing feedback.** Don't file it yourself: an issue is public, so let the user decide. Link: https://github.com/froala/froala-skills/issues/new?template=skill-feedback.yml

Include in the report:

- **Skill:** `froala-ai-assist`
- **Froala version:** `froala-editor` and wrapper versions from `package.json` or `node_modules/froala-editor/package.json`
- **What was wrong:** the skill's statement, the exact error message or behaviour, and the fix or workaround if one was found
- **Agent** (coding tool and model, if known) and a short way to reproduce

Leave out licence keys, API keys, tokens and other secrets (write `<redacted>`), and any private customer content.

Not for this form: bugs in the Froala editor itself and licence or billing questions (contact support@froala.com).
